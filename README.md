# Diffusion Variational Autoencoder for Multi-Step Stock Price Prediction

A hybrid deep learning project combining Variational Autoencoders and Diffusion Models to tackle stochasticity in multi-step stock price forecasting.

---

## Features

- Diffusion-enhanced Variational Autoencoder (D-Va)
- Handles long-term dependencies & market noise
- Multi-step stock price forecasting
- Real-time prediction UI using Streamlit + Colab

---

## Tech Stack

- Python 3.8+
- TensorFlow / Keras
- Scikit-learn, NumPy, Pandas
- Streamlit (UI)
- Google Colab (Backend)
- Yahoo Finance API
